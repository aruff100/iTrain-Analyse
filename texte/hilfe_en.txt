iTrain-Analyse – Help

WHAT THE PROGRAM IS FOR
The program collects all files the analysis prompt needs: the prompt, the layout file, the manual as text with page markers and the release notes. The analysis itself is done by your AI assistant. The program sends nothing to an AI and does not change your layout file.

IMPORTANT: FREE AND PAID AI SERVICES
An analysis is a very large task: manual (about 500 KB of text), layout file and prompt together. All providers limit usage, free plans especially. There the analysis often stops, or the AI checks only part of the file.
In the author's experience (as of November 2026), only Claude with the paid Pro plan carried out the analysis flawlessly. Other AI assistants and free plans ran into their usage limits and were overloaded by such an analysis.
Claude Pro has usage limits too. According to Anthropic, however, they are at least five times the free plan per session and reset every five hours.
The Pro plan can be cancelled monthly. If you only want to analyse for a while, register at claude.ai, take out Pro for one month, pay and cancel right away. The cancellation only takes effect at the end of the paid month; until then Pro remains usable. This gives you about 30 days in which you can analyse as much as the limits allow. If you do not want to renew, cancel at least 24 hours before the next billing date.
Prices and terms may change; the information on claude.ai applies.

BEGINNER OR ADVANCED
Advanced: the complete analysis with the prompt, as described on itrainplus.de.
Beginner: the beginner prompt. It checks your project in rounds, one topic with at most three points per round, and explains every point with click steps and the manual page. After each round you change the points in iTrain, run the diagnostics, save and upload the .tcdz with a picture of the diagnostics again in the same chat. You only need the program for the start. Direct mode, extras, forum post and release notes are not used. The button "Beginner guide" explains the procedure in detail, including costs and limits. The prompt was tested with Claude on a test layout with a good result.

HOW IT WORKS
1. Choose the layout file. The list shows the files from the iTrain folder "layouts", the most recently changed at the top. "Browse" lets you choose a file elsewhere.
2. Click "Start quick check". The program checks the layout file without AI and shows the result in a separate window (with "Print" and "View check report"). "Done" ends here; "Continue to AI analysis" opens three step windows one after the other. In the first you choose the prompt language: Deutsch/Nederlands or English/Français/Español/Italiano.
3. Optionally direct mode: the AI then asks no questions and delivers everything in one reply. Below it choose language, format and the extras. When switched on, no extra is ticked. Extra 3 "check signals" is described below in the section SIGNALS (EXTRA 3).
   In the field "Additional task for the AI" you can, also without direct mode, ask a question of your own, e.g. about a relay or the sequence of an action. The AI answers it at the front of the analysis document.
4. Optionally "Include forum post" and enter the address of the post. The iTrain forum shows posts to logged-in users only. The AI can therefore only read the post if it may use a browser in which you are logged in to the forum: with Claude, the "Claude in Chrome" extension (Chrome must be open and the extension connected) or the browser of the Claude app, in which you log in to the forum once. Other AI assistants usually cannot do this. In that case open the post in your browser, copy the text and paste it into the field "Post text"; the program adds it to the other files as Forum_Beitrag_<number>.txt.
5. In the last step window click "Assemble". This fills the working folder; the "Progress" field shows what was collected and what is missing. "Run" then puts the package into the clipboard. "Cancel" closes the steps without putting anything into the clipboard.
6. Then the window with the analysis package opens. Open a new, empty chat in your AI assistant, drag the blue box with all files into the message field, add the text with "Copy" and send. The window can be printed.
Files and text are also on the clipboard: Ctrl+V (Mac: Cmd+V) in the message field pastes them if your chat interface supports it.

WHAT IS COLLECTED
Prompt: comes from the web server itrainplus.de. A version is included in the program. At every start the program checks whether there is a newer one on the server and asks before downloading. A local folder can be set instead of the server.
Manual: comes from the Berros download page. At start the program checks whether there is a newer version and asks before downloading. The PDF is converted to text once; each page begins with "===== Seite x von N =====" so that the AI can give page references.
Release notes: come from the docs folder of your iTrain installation, shortened to the versions from 6.0 on. If they are missing, the program asks whether to continue anyway.
Signal file (only with extra 3): Addon_Signals_EN_FR_ES_IT or Zusatz_Signale_DE_NL, comes like the prompt from the web server itrainplus.de or from the program.
Layout file: the .tcdz is unpacked; the AI gets the .tcd inside.
Everything is stored in the working folder. Prompt, manual PDF and manual text are reused for the next analysis as long as they are current.

PRE-CHECK AND CHECK REPORT
Before the chat the program checks the layout file itself according to fixed rules: counts for the entry check, feedback delays, missing and duplicate addresses, block and feedback lengths, block connections, stop points, vehicles and trains, all routes (connections, "Strict", repetition, gauge, permissions of train, locomotive, wagon and train type, superfluous markers) and the tables for extras 1 and 2. The result is attached as the file Pre-check.txt (Vorpruefung.txt for German/Dutch). The AI adopts these values, verifies some of them against the layout file and adds what only it can do: actions, relationships, train options, signals and explanations. This saves calculation work and makes the results more reliable. The complete list of checks is shown in the main window under “What the quick check covers”.
Quick check without AI: the button "Start quick check" in the main window runs only this check. The result appears in a separate window with paragraphs on what was checked, what the AI checks in addition and how many tokens the AI saves. There you can print the check report and view it as PDF. If that is enough for you, click "Done"; the program then points out that the quick check is superficial and can make mistakes. "Continue to AI analysis" leads through the steps prompt and output, additional task and forum post, assemble. How large the saving is depends mainly on the size of the layout file.
Manual excerpt: instead of all 252 pages only an excerpt with the pages that the prompt, the signal file and the pre-check cite goes into the chat (about 40 pages). This saves most of the tokens. It only works with the German manual. With an additional task for the AI or a forum post the complete manual is always included. Switch off under Settings > Preferences > Paths.

EXTRAS
Extra 1 is the train table, extra 2 the check of platforms, block lengths and stop points, extra 3 the check of the signals (from prompt 2.5 on, direct mode only). The extras can be chosen individually. In direct mode the program writes e.g. "Extras Train table, Platforms and Signals" or "Extras Signals" into the text for the chat; in dialogue mode the AI asks about extras 1 and 2 with four answers: both, train table only, platforms only, none.

SIGNALS (EXTRA 3)
With the check box "Extra 3: check signals" in direct mode the AI additionally checks the signals of your layout. The basis is the "Rules for iTrain Signals" by Berros (https://berros.eu/download/tutorial/). When direct mode is switched on, no extra is ticked; you choose yourself.
For this the program adds the file Addon_Signals_EN_FR_ES_IT_v….txt (German/Dutch language group: Zusatz_Signale_DE_NL_v….txt) as a separate file to prompt, manual and layout file and names "Signals" in the direct mode line. The file lies in the folder of the run in the working folder.
The check covers:
- whether every signal is in the correct field of the block editor (Home Signal, Shunt Signal, Warning Signal in the section "Signal" or "Block"),
- whether multi-role signals (e.g. exit signal with Sh1, Ks and Hl signals) are only in the field "Home Signal",
- whether a signal is assigned in the block to which it is grouped in the switchboard,
- whether drawn signals are not assigned to any block,
- whether the order in the switchboard matches the rules (Warning Signal with or without a gap before the Home Signal, Shunt Signal before the Home Signal).
The result appears in the analysis document as "Extra 3: Signal check" with its own findings S1, S2 etc.; without findings it says "Signals checked (<count> signals), no findings". The AI reads the order in the switchboard only from the sequence of switchboard items; such findings are marked "probably". On which side of the track a signal stands cannot be checked.
Like the prompt, the add-on file comes from the web server itrainplus.de; a version is included in the program. It is a summary of the Berros rules. If Berros changes the rules or publishes a newer version, the program reports this at start and when assembling in the "Progress" field; the add-on file is then revised and provided as a new version.

ROUTES
From prompt 2.3 on the AI checks all train routes for feasibility in every analysis: whether the blocks exist, whether they follow each other in the track plan in the given direction, whether the option "Strikt" (strict) can be met, whether repeated routes end where they start, and whether lists with "Optimal length" contain a suitable block. If there is nothing to report, "No findings" says: Routes checked, no findings.

VIEW
After assembling, the "View" menu shows the prompt text, the signals text (with Extra 3), the release notes text and the manual text in a separate window. Before that the entries are greyed out. With "Refresh" at the top of the menu the program checks whether prompt, signals and manual are the current version, downloads new versions after asking and provides all documents in the working folder under "Dokumente"; after that they can be viewed and edited without assembling. With "Edit" you can extend the text, e.g. append your own check rules to the prompt. Copy, paste and cut work with Ctrl+C, Ctrl+V and Ctrl+X (Mac: Cmd) or with the buttons.
"Save" stores the version as "…_bearbeitet.txt" in the subfolder "Bearbeitet" of the working folder and thereby replaces the original on the clipboard, in the result window and in the layout folder. The original is kept; "Restore original" switches back. The text for the chat names the edited files for the AI, and the program points this out to you when copying.
At the next assembly the program asks whether to use the edited version or the original. If the original has changed in the meantime (e.g. a new prompt), the question says so.

IF PASTING DOES NOT WORK
Some chat interfaces do not accept files from the clipboard. Then drag the files from the result window or from the working folder ("Open working folder") into the chat and copy the text with "Copy".
If the AI rejects the .tcd, switch on "Attach layout file as .tcd.xml" and assemble again.

SETTINGS
Settings > Preferences:
Paths: prompt source (web server or local folder), folder of the layout files, iTrain docs folder, address and language of the manual.
Working folder: one subfolder per layout with the files for the chat, plus the cache .cache.
Colours: light or dark.
Language: language of the user interface.

NOTES
Your layout file is sent to the AI provider when you paste it.
Any AI can be wrong. Check findings in iTrain before you change anything, and back up your project first.
